# Getting help

- **Download a tool or read its documentation:** <https://deviops.app/tools/>
- **Something does not work:** open an issue in the tool's repository and use the bug report form.
- **Ask for a feature or vote on one:** <https://deviops.app/requests/> or an issue in the tool's repository.
- **Security problem:** report it privately. See [SECURITY.md](SECURITY.md).
- **Anything else:** email admin@deviops.app.

Please never send real evidence, case material, or personal data. A synthetic file or a description of the problem is enough.

DEVI tools are free and offered as is. We read every report, but we cannot promise a response time.
