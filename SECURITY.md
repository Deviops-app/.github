# Security policy

DEVI tools are used to handle digital evidence, so security and correctness reports are handled first.

## Reporting a vulnerability

Please report security problems **privately**. Do not open a public issue.

- **Email:** admin@deviops.app, with the tool name and "security" in the subject line.
- **GitHub:** use **Report a vulnerability** on the Security tab of the affected repository to open a private advisory, where that option is shown.

Include the tool and version, the Windows version, and the steps or input needed to reproduce the problem. **Do not include real evidence, case material, or personal data.** A synthetic file or a description of the input is enough.

## What to expect

- We confirm we received your report, usually within a few business days.
- We keep you updated while we investigate and fix it.
- We credit you in the release notes when the fix ships, unless you ask us not to.
- Please give us a reasonable chance to release a fix before you disclose the problem publicly.

## Supported versions

Only the latest release of each tool receives security fixes. Check for updates in the app, or download the latest release from <https://deviops.app/tools/>.

A repository can add its own `SECURITY.md` with details that apply only to that tool. That file takes priority over this one.
