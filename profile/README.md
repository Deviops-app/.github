## DEVI

**Intelligence by Design.** Forensic tools for verified digital forensic examiners, from DEVI Ops LLC.

Every DEVI tool works offline, opens evidence read-only, says plainly what a result can and cannot show, and ships signed with a published SHA-256.

### Tools

| Tool | What it does |
| --- | --- |
| [DEVI Validate](https://deviops.app/tools/devi-validate/) | Re-checks the hash values another tool recorded for your evidence, offline and read-only, and writes a PDF verification record. |
| [DEVI Decrypt](https://deviops.app/tools/devi-decrypt/) | Decrypts Apple and iCloud OpenPGP provider returns offline on Windows. |
| [DEVI Registry](https://deviops.app/tools/devi-registry/) | A sourced database of app and artifact metadata for examiners, with an offline Windows app. |

Downloads are for approved accounts. Request access at **[deviops.app](https://deviops.app)**.

Please never send real evidence, case material, or personal data.

DEVI tools do not carry a court, standards-body, or laboratory certification. Each lab should validate a tool under its own procedures before relying on it in casework.
